# 输入约定与算法说明

以下为按代码和已有输入约束整理的自写摘要。各程序独立运行，输入必须满足对应范围。这里没有收录原始题面、插图或在线评测成绩。

## A：两个最大值

输入测试组数 T，每组为 n 和 n 个非负整数；输出其中两个元素的最大和。相同数值的不同元素可以同时选取。T≤10、2≤n≤200000、数值≤10^9。时间 O(n)，额外空间 O(1)。

## B：单词匹配

按行读到 EOF，以空格分词；忽略 ASCII 字母大小写。一个词满足前缀 `cac`、后缀 `tus` 或包含 `cactus` 之一，该行计数一次。连字符属于词的一部分。输入由英文字母、空格、连字符组成，总长度≤100000、行数≤1000。输出匹配行数；时间与输入总长度成正比。

## C：多边形面积

输入组数 t，每组为 n 及按边界顺序给出的 n 个整数坐标。多边形简单且边平行坐标轴。t≤5、n≤400000、坐标绝对值≤50000。计算相邻点叉积和的绝对值除以2；这些轴对齐整数坐标多边形的面积为整数。时间 O(n)，额外空间 O(1)。中间计算使用 `long long`。

## D：经过指定点的路线

输入 n/m/k、m 条无向正权边、k 个指定点。求从1到n且至少经过一个指定点的最短路线，允许重复经过点和边。答案为所有指定点 s 上 `dist(1,s)+dist(n,s)` 的最小值。保证存在合法路线；n≤100000、m≤500000、k≤n、边权≤1000，允许重边和自环。两次堆优化 Dijkstra，懒删除堆项；时间 O((n+m)log(m+1))，空间 O(n+m)。

## E：绝对值函数

输入操作数 Q（≤200000）。`1 a b` 加入 `|x-a|+b`；`2` 输出使累计和最小的最小整数 x 及最小值。第一个操作为更新，a/b 绝对值≤10^9。所有 a 先离散化，用计数树状数组求下中位数，用值和树状数组计算两侧距离和；b 只影响最小值。每步 O(log Q)，预处理 O(Q log Q)，空间 O(Q)。

## F：指令修改

输入非空 F/T 字符串（长度≤100）和修改次数 n（1..50）。F 沿当前方向走一步，T 反向；初始在0朝正方向。一次修改翻转某个字符，允许重复修改同一位置，要求恰好修改 n 次；输出最终位置绝对值的最大值。

DP 记录消耗修改次数、偏移位置、方向。最终有效翻转次数 i 必须满足 i≤n 且 n-i 为偶数，多出的修改可两次抵消。长度为 L 时，时间 O(nL²)，空间 O(nL)，以滚动数组处理字符。

## G：编号树 LCA

预先生成 f1=f2=1 的斐波那契序列。根为1；对于 x>1，取首个满足 fd≥x 的 d，父节点为 `fd-x+1`。输入 t 组正整数 a/b（t≤100000，编号≤2^61），输出由此编号树定义的最近公共祖先。先沿父节点求深度，再对齐深度向上跳转。编号缩小约束树高为对数级；当前实现每次父节点查询二分查找斐波那契阈值，没有倍增表。

## H：字符图案

输入 n（0..6）。初始图形为3×3四瓣结构，填充字符为小写 `o`，其余为空格。奇数步把现有图形排列为2×2；偶数步在四个方向复制并使用 `len-1` 作为偏移。输出行末空格裁剪。最大 n=6 时边长562，固定600×600数组足够容纳。按最终图形面积计，时间/空间均为 O(L²)。
